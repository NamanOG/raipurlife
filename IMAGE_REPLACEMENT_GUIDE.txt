SECTION 3: IMAGE SPECIFICATIONS
================================================================================

RECOMMENDED IMAGE SIZES:
-----------------------
Hero Backgrounds:        1920x1080px (or larger), landscape orientation
Tourism Places:          800x600px minimum, landscape orientation
Food Items:              600x600px, square or landscape orientation
Event Photos:            1200x800px, landscape orientation
Gallery Images:          1000x750px, landscape orientation
Featured Places:         800x600px, landscape orientation
Profile Pictures:        400x400px, square orientation

FILE FORMATS:
------------
- Use .jpg or .jpeg for photographs (better compression)
- Use .png for images with transparency or graphics
- Use .webp for best web performance (optional)

QUALITY:
--------
- Compress images to 80-90% quality to reduce load time
- Ensure images are web-optimized (under 500KB each if possible)
- Use tools like TinyPNG or ImageOptim for compression

STEP-BY-STEP PROCESS
================================================================================

1. CREATE FOLDER STRUCTURE:
   - Open: d:\Projects\Web Projects\raipurlife\public\
   - Create folders: hero, tourism, nature, food, events, gallery, history, places, profiles

2. TAKE/COLLECT PHOTOS:
   - Use specifications in Section 3
   - Capture actual Raipur locations matching descriptions
   - Ensure good lighting and quality

3. OPTIMIZE IMAGES:
   - Resize to recommended dimensions
   - Compress to reduce file size
   - Save in appropriate formats (.jpg for photos, .png for graphics)

4. SAVE TO FOLDERS:
   - Place images in their respective folders as outlined
   - Use descriptive filenames (lowercase, hyphen-separated)

5. UPDATE CODE:
   - Follow the "FILES TO UPDATE" sections for each image
   - Find the line numbers mentioned
   - Replace the old path with the new path
   - Save all modified files

6. TEST WEBSITE:
   - Run: npm run dev (or bun dev)
   - Check all pages to ensure images load correctly
   - Verify responsive display on different screen sizes

================================================================================
NOTES & TIPS
================================================================================

✓ All image paths in public folder should NOT include "/public/" prefix
  WRONG: src="/public/hero-bg.png"
  RIGHT: src="/hero-bg.png"

✓ Always use forward slashes (/) in image paths, even on Windows

✓ Keep original aspect ratios when resizing to avoid distortion

✓ Consider creating @2x versions for retina displays (optional)

✓ Use descriptive, SEO-friendly filenames (e.g., "raipur-skyline-sunset.jpg")

✓ After updating all images, clear browser cache to see changes

✓ Keep a backup of original stock images in case you need to revert
